# Diretrizes de Contribuição

Todas as contribuições, relatórios de bugs, correções de bugs, melhorias na documentação, aprimoramentos e ideias são bem-vindas.

## Como Contribuir

1. **Relatar Bugs**: Se você encontrar um bug, por favor abra uma *Issue* descrevendo o problema e como reproduzi-lo.
2. **Sugerir Melhorias**: Ideias e sugestões para novas funcionalidades também podem ser enviadas criando uma *Issue*.
3. **Enviar Alterações**:
   - Faça o **fork** do repositório.
   - Crie uma nova branch para a sua alteração (`git checkout -b minha-contribuicao`).
   - Faça o commit de suas alterações (`git commit -m 'Adiciona melhoria'`).
   - Faça o push para a sua branch (`git push origin minha-contribuicao`).
   - Abra um **Pull Request**.

Agradecemos a sua contribuição para tornar este projeto melhor!
